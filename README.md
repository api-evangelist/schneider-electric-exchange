# Schneider Electric Exchange (schneider-electric-exchange)
Schneider Electric Exchange is a developer platform providing APIs for EcoStruxure energy management, building automation, industrial IoT, and commerce partner integrations. The Exchange platform enables partners and developers to build integrations with Schneider Electric products and services.

## APIs

### EcoStruxure IT Expert API
The EcoStruxure IT Expert API gives users a way to integrate EcoStruxure IT into their own environments, with functionalities that allow users to maintain a local data store or build applications that react to changes in their critical infrastructure.
